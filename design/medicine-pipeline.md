# Medicine pipeline — oncology translational map

How curated literature becomes real oncology medicines (and why Ralph never invents milligrams).

## Stages

1. **Target / hallmark** — driver oncogene, surface antigen, neoantigen class, TME node
2. **Modality choice** — small molecule, mAb, ADC, bispecific/TCE, CAR-T/NK, vaccine, radio-ligand, cell/gene
3. **IND-enabling** — tox, CMC, assay (including MRD sensitivity disclosure)
4. **FIH → expansion** — dose, DLTs, early ORR/CR (hypothesis-generating)
5. **Randomized** — PFS/EFS/DFS/OS; cure-fraction language only with long FU + controls
6. **Label / post-marketing** — secondary malignancy, infection, organ toxicities banked

## Honesty gates (Ralph laws)

| Trap | Rule |
|------|------|
| COMPLETED on CT.gov | ≠ Results tables / manuscript |
| Press topline | Bank as medium until peer-reviewed HR/KM |
| pCR / MRD-neg | Surrogate — not automatic cure |
| Sister indication dose | Adjacency ≠ invention |
| Single-arm CAR-T time-to-event | FDA caution — need comparator for strong claims |
| Name collisions | Verify NCT/drug identity before banking |
