# Oncogenic driver / target catalog (v1)

Prioritized targets and modalities for the Hybrid D climb. Not exhaustive. Not dosing advice.

## Class A — proven cure-adjacent / population cure

| Target / context | Modality | Evidence bar | Notes |
|------------------|----------|--------------|-------|
| Childhood B-ALL blasts | Multiagent chemo | Population cure >90% | Existence proof |
| Adult BCP-ALL MRD-neg | Blinatumomab consolidation | Ph3 OS (E1910) | Curative-intent |
| CD19+ B-ALL / LBCL | CD19 CAR-T | FDA + long-term plateaus | Subset durable; escape real |
| BCR-ABL1 CML | TKIs → TFR | TFR trials | Functional cure subset |
| Metastatic GCT | Cisplatin regimens | Historical cure | Solid-tumor cure paradigm |
| Advanced melanoma | Dual CPI | OS plateau | IO cure-fraction |

## Class B — deep remission, cure not population-level

| Target | Modality | Notes |
|--------|----------|-------|
| BCMA | CAR-T / teclistamab | Deep MRD; most RRMM still progress |
| GPRC5D | Talquetamab | Dual with BCMA (MonumenTAL-6 topline) |
| CD19 ADC | Loncastuximab (ZYNLONTA) | LOTIS-5 confirmatory PFS |
| HER2 / HER2-low | T-DXd | Metastatic gains; adjuvant cure-intent separate |
| EGFR / ALK / KRAS G12C | TKIs | Resistance clock; adjuvant (ADAURA) cure-intent |

## Class C — sentinel hard solids (climb)

| Disease | Lead approaches | Status |
|---------|-----------------|--------|
| Resected PDAC | Autogene cevumeran + atezo + mFFX | Ph1 signal; IMCODE003 recruiting |
| IDH-wt GBM | Neoadjuvant triplet CPI | Case-level; trials planned |
| TNBC (high-risk / metastatic) | Personalized neoantigen vaccines ± CPI | Ph1 adjuvant; metastatic early |

## Class D — resistance / escape nodes

- Antigen loss (CD19− relapse) → dual-target CAR / rituximab combinations
- TME exclusion / stroma (PDAC) → vaccine + chemo + IO stacks
- Steroid / myeloid suppression (GBM) → neoadjuvant window before resection
- Assay honesty (MRD) → store sensitivity, timepoint, denominator
